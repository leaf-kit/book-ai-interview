# q033, 학습이냐 파인튜닝이냐 프롬프트냐

**한 줄 요약.** 무엇을 골랐는지는 누구나 답한다. 안 고른 쪽을 어디까지 가 봤는지에서 갈린다.

**판정.** 안 고른 쪽이 나오고, 그걸 어디까지 가 봤는지가 나오면 통과입니다. 방식을 한 번 갈아탄 이야기가 나오면 아주 좋은 신호예요. 양쪽에 다 서 본 겁니다. 셋을 다 설명하는데 자기가 만진 건 하나뿐이고, 안 고른 이유가 교과서 문장이면 안 보냅니다. 검토했다는 말을 파고들어도 크기가 안 나오는 경우도 같습니다. 기록에는 이렇게 적습니다. 프롬프트로 시작해 0.71에서 막혔고, 티켓 4천 건으로 파인튜닝해 0.83을 얻었다가, 라벨이 낡는 비용 때문에 두 달 뒤 걷어냈다.

**꼬리 질문.** 방식을 물으면 고른 쪽 이야기가 옵니다. 그래서 안 고른 쪽을 어디까지 가 봤는지 묻습니다. 돌려 봤냐는 한 마디가 검토의 크기를 그 자리에서 드러내요. {파인튜닝 쪽은 어디까지 가 보셨어요? 한 번은 돌려 보셨나요?} {그때 뭐가 걸려서 접으셨죠? 지금 다시 하면 같은 선택 하시겠어요?}


이유와 이야기는 책에 있습니다.
