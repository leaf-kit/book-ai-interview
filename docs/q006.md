# q006, 같은 질문, 두 답변

**한 줄 요약.** 같은 질문에 대한 두 답변을 나란히 놓으면 잣대를 안 만들어도 차이가 먼저 보인다.

**판정.** 두 답을 가른 것을 문장 하나로 적을 수 있으면 통과입니다. 적히는 순간 그게 이 자리의 잣대가 됩니다. 두 답이 안 갈리면 지원자가 아니라 질문을 의심합니다. 안 갈리는 질문은 그날로 질문 목록에서 뺍니다. 디브리프에는 이렇게 적습니다. 숫자가 하나도 없었고, 버린 기준을 두 번 물었지만 안 나왔고, 데이터를 나눈 단위도 끝까지 안 나왔다.

**꼬리 질문.** 어떤 데이터로 했냐고 물으면 절차가 나옵니다. 그래서 버린 것 쪽으로 돌립니다. 버린 것은 만든 사람만 알거든요. {그 데이터에서 버린 게 있어요? 뭘 기준으로 버리셨어요?} {그거 나눌 때 단위가 뭐였어요? 왜 그 단위로 나누셨어요?}


이유와 이야기는 책에 있습니다.
