# q028, 되돌린 적이 있는가

**한 줄 요약.** 되돌리기에는 버린 양이 붙는다. 버린 양은 지어내기 어렵다.

**판정.** 버린 양이 숫자로 나오면 통과입니다. 3주, 400줄, 두 달처럼요. 그리고 왜 그때 못 버렸는지까지 말하면 그건 아주 좋은 신호입니다. 조정과 수정으로만 답하고, 양을 물어도 일부라는 말로 답하면 안 보냅니다. 되돌려 본 적이 없다는 건 큰 결정을 안 맡아 봤다는 뜻일 수도 있으니, 그때는 다음 라운드에 확인할 자리로 적어 넘깁니다. 기록에는 이렇게 적습니다. 하이브리드 검색 3주를 버렸고, 근거는 0.01이었고, 아까워서 일주일을 더 붙들었다고 스스로 말했다.

**꼬리 질문.** 되돌린 적을 물으면 조정 이야기가 옵니다. 그래서 버린 양을 묻습니다. 양을 물으면 고친 것과 버린 것이 갈립니다. {그때 버린 코드가 얼마나 됐어요?} {그걸 더 일찍 버렸어야 했다고 생각하세요? 언제쯤이요?}
