# q040, 남의 코드를 읽히는 과제

**한 줄 요약.** 잘 짜였다는 소감은 아무 코드에나 붙는다. 깨지는 입력을 하나만 대게 한다.

**판정.** 입력을 하나라도 값으로 대고 코드의 어느 줄 때문인지를 짚으면 통과입니다. 버그인지 아닌지 모르겠다고 스스로 갈라 말하면 아주 좋은 신호예요. 구조가 좋다거나 예외 처리가 필요하다고만 하고, 입력을 하나 대 달라고 다시 물어도 비정상적인 입력이라는 식으로만 답하면 다음 라운드로 안 보냅니다. 기록에는 이렇게 적습니다. 같은 낱말을 두 번 넣으면 점수가 두 배가 된다는 것을 값으로 짚었고, 질의 낱말을 안 센다는 줄까지 댔으며, 결과 길이 문제는 버그가 아닐 수도 있다고 스스로 갈랐다.

**꼬리 질문.** 코드를 보여주면 소감이 옵니다. 소감은 어느 코드에나 붙어요. 그래서 값을 하나 달라고 합니다. 값을 대면 이유가 따라 나오고, 그 이유가 어느 줄을 읽었는지를 말해 줍니다. {이 코드에서 깨지는 입력을 하나만 찾아 주세요.} {그게 왜 깨지죠? 어느 줄 때문인가요?}

- 과제 코드: `samples/g12/retrieve.py`

이유와 이야기는 책에 있습니다.
