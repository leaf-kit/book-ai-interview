# q004, 빈자리 일곱 군데

**한 줄 요약.** 빈자리는 아무 데나 안 생긴다. 일곱 자리를 알고 있으면 45분에 다 훑는다.

**판정.** 일곱 칸 중 넷 이상이 두 번 안에 채워지면 통과입니다. 일곱을 다 채우는 사람은 드물어요. 저도 제 프로젝트로 다 못 채웁니다. 4번 칸이 끝까지 안 채워지면 안 보냅니다. 누가 한 일인지 모르면 나머지 여섯 칸의 숫자도 누구 것인지 모르게 되거든요. 디브리프에는 이렇게 적습니다. 일곱 칸 중 둘만 채워졌고, 4번이 비어 있고, 직접 쓴 코드가 어디냐고 물었지만 범위가 안 좁혀졌다.

**꼬리 질문.** 맡은 부분을 물으면 참여와 담당과 리딩이 한 답에 다 들어옵니다. 그래서 코드로 물어요. 코드는 경계가 또렷하거든요. {그중에 코드를 직접 쓰신 데가 어디예요?} {그 넷 중에 다른 분이 하신 건 어디였어요?}
