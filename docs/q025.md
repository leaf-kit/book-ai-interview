# q025, 안 해 본 것을 물어 확인하는 법

**한 줄 요약.** 함정을 파지 않고도 경계를 안다. 어디까지 해 봤냐고 범위를 물으면 된다.

**판정.** 범위를 물었을 때 위든 아래든 경계를 스스로 그으면 통과입니다. 얕다고 답한 것 자체는 감점이 아니에요. 얕은 자리를 아는 게 중요합니다. 경계를 안 긋고 계속 있다 없다로 답하고, 했으면 남았을 사실을 물어도 안 나오면 안 보냅니다. 한 줄로 적힌 것이 실제로 무엇이었는지 확인이 안 된 채로 뽑으면 서로 힘들어집니다. 기록에는 이렇게 적습니다. 파인튜닝은 튜토리얼 수준이라고 스스로 그었고, 왜 안 했는지 이유까지 말했고, 검색 쪽은 2년이라고 밝혔다.

**꼬리 질문.** 해 보셨냐고 물으면 예가 옵니다. 그래서 어디까지냐고 범위를 묻습니다. 그리고 했으면 반드시 남았을 사실을 하나 물으면 경계가 확인됩니다. {그거 어디까지 해 보셨어요?} {그 학습이 몇 시간짜리였어요? 어디서 돌리셨죠?}


이유와 이야기는 책에 있습니다.
