# q022, 실물을 먼저 시킨다

**한 줄 요약.** 과제는 채점하지 않는다. 대화를 여는 입구로 쓴다. 근거 없이 정한 값을 묻는 자리다.

**판정.** 과제에서 근거 없는 값을 스스로 짚고 왜 못 정했는지 말하면 통과입니다. 값을 다 정해 왔다면 그중 하나의 근거를 물어서 확인합니다. 바꿀 부분을 물었는데 시간과 완성도 이야기만 하고, 자리를 짚어 달라고 해도 영역으로만 답하면 안 보냅니다. 자기 결과물을 다시 안 읽어 본 거예요. 기록에는 이렇게 적습니다. 자르는 함수를 짚었고, 과제 중 세 번 고쳤고, 겹치는 값에 근거가 없다고 스스로 말했다.

**꼬리 질문.** 바꿀 부분을 물으면 완성도 이야기가 옵니다. 그래서 함수 하나로 좁힙니다. 어느 함수부터냐고 물으면 불안했던 자리가 나오거든요. {테스트를 쓴다면 어느 함수부터 쓰시겠어요?} {그 함수에서 뭐가 제일 깨지기 쉬울 것 같으세요?}

- 과제 코드: `samples/g12/retrieve.py`

이유와 이야기는 책에 있습니다.
