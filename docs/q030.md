# q030, 데이터가 어디서 왔는가, 라벨은 누가 붙였나

**한 줄 요약.** 데이터를 받아 쓴 사람과 데이터를 만든 사람은 라벨 이야기에서 갈린다.

**판정.** 라벨을 붙인 사람이 나오고 그중 갈린 이야기가 나오면 통과입니다. 겹쳐 준 건수와 갈린 건수처럼 숫자가 붙으면 더 좋고요. 데이터의 출처를 물어도 가공 이야기로만 답하고, 라벨을 누가 붙였냐고 물어도 팀에서 진행했다고 답하면 다음 라운드로 안 보냅니다. 기록에는 이렇게 적습니다. 상담 기록 2년치, 라벨은 본인이 붙였고, 상담사 두 분의 일치도를 200건으로 재서 60건이 갈린 것을 확인했다.

**꼬리 질문.** 데이터를 물으면 가공 이야기가 옵니다. 그래서 라벨을 누가 붙였는지 묻습니다. 사람을 물으면 갈린 이야기가 따라 나와요. 두 사람이 붙이면 반드시 갈리거든요. {라벨은 누가 붙였어요?} {두 분이 다르게 붙인 건 없었어요? 그때 어떻게 하셨죠?}


이유와 이야기는 책에 있습니다.
