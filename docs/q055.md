# q055, 같이 일할 수 있는가

**한 줄 요약.** 성격을 보지 않는다. 모른다고 말하는가와 어긋난 걸 짚는가만 본다.

**판정.** 지금 모르는 것 하나를 자리로 대고, 짐작과 확인을 갈라 말하면 통과입니다. 제가 어긋나게 말한 자리를 짚고 되물으면 아주 좋은 신호예요. 배우는 걸 좋아한다거나 부족한 점이 많다고만 하고, 하나만 대라고 두 번 물어도 자리를 못 대면 다음 라운드로 안 보냅니다. 성격이나 인상은 기록에 안 적습니다. 기록에는 이렇게 적습니다. 임베딩 모델을 왜 그걸로 정했는지 모른다고 자리로 댔고, 바꿨다가 나빠진 이유는 설명 못 하겠다며 짐작과 확인을 갈랐으며, 어긋난 순서를 한 번 짚었다.

**꼬리 질문.** 같이 일할 수 있냐는 건 물어서 알 수 없습니다. 그래서 모르는 자리를 하나 달라고 합니다. 자리를 대면 짐작과 확인이 갈리고, 그 가르는 습관이 팀에서 그대로 나옵니다. {지금 하시는 일 중에 아직 잘 모르겠는 게 뭐예요?} {그건 짐작이세요, 확인해 보신 거예요?}


이유와 이야기는 책에 있습니다.
