# q026, 남의 일과 내 일을 가르는 질문

**한 줄 요약.** 누가 정했는지를 물으면 책임이 어디 있었는지가 나온다. 반대한 사람을 물으면 더 나온다.

**판정.** 결정마다 주인이 나오고, 자기가 진 이야기가 하나라도 있으면 통과입니다. 받은 결정이 많은 것 자체는 감점이 아니에요. 받았다고 말하는 게 중요합니다. 계속 팀에서 정했다로 답하고, 반대한 사람을 물어도 없었다고 하면 안 보냅니다. 그건 결정이 오간 자리에 이 사람이 없었다는 뜻일 가능성이 큽니다. 기록에는 이렇게 적습니다. 제안은 본인이 했고 결정은 리드가 했다고 갈랐고, 자기 안이 진 이유를 화면을 안 봤기 때문이라고 스스로 댔다.

**꼬리 질문.** 누가 했냐고 물으면 팀이 나옵니다. 그래서 반대한 사람을 묻습니다. 반대를 기억하려면 그 자리에 있어야 하거든요. {그때 반대하신 분이 있었어요? 누가 어떤 이유로요?} {지금 보면 그분 말이 맞았던 것 같으세요?}


이유와 이야기는 책에 있습니다.
