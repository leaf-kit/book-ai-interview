# q061, 질문 61개를 한 장으로

**한 줄 요약.** 질문은 쓸수록 닳는다. 넣는 규칙 말고 빼는 규칙이 있는지를 본다.

**판정.** 빼는 규칙이 있고 지금까지 몇 개를 뺐는지 대면 통과입니다. 유출된 질문 중에 안 뺀 것이 있고 그 이유를 대면 아주 좋은 신호예요. 위키에 모아 두고 자유롭게 쓴다고만 하고, 뺀 질문이 몇 개냐고 물어도 없다고 하면 그 은행은 아직 창고입니다. 쓴 횟수를 안 세는 경우도 같이 적어 둡니다. 기록에는 이렇게 적습니다. 쓸 때마다 한 줄씩 적고 열두 번이 넘으면 물러나게 해서 지금까지 넷을 뺐으며, 유출된 것 하나는 우리 코드를 가리켜서 그냥 뒀다고 말했다.

**꼬리 질문.** 질문 은행을 물으면 목록 이야기가 옵니다. 목록은 늘리기 쉬워요. 그래서 뺀 것을 묻습니다. 뺀 건수를 대면 쓴 횟수를 센다는 뜻이고, 세는 팀만 은행을 계속 씁니다. {거기서 빠진 질문이 지금까지 몇 개예요?} {안 뺀 것 중에 밖에 돈 게 있나요? 그건 왜 두셨죠?}
